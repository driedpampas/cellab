CelLab · Deliverable 2 · state hashes play the role of the visited set in state-space search

A finite grid with deterministic rules must eventually repeat a state. When it does, the whole future is known: a cycle of length 1 is a stable state, and a configuration not seen by then never appears. For very large N, the state equals the state at start + (N - start) mod length, which we checked against direct simulation. For random rules a repeated grid is not a guaranteed cycle, and the answers say so.
