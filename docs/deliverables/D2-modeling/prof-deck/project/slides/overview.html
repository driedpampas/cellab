Overview

How the system is organised

Two text files go in: what the automaton is, and what to do with it.

One loop repeats every step: compute, fingerprint, save, check the questions.

A run folder comes out: answers, saved states, pictures.

CelLab · Deliverable 2 · Python, NumPy, pydantic

In AI terms this is a state-space model: a state is the grid, the transition function is one step of the rules, the initial state comes from the experiment file, and the questions are goal tests. The fingerprint table is the visited set from search algorithms.
