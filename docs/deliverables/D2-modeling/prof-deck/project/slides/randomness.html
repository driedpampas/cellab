Fixed randomness

Same seed, same result

One seeded generator per run, random numbers drawn in a fixed order, and its state saved in every checkpoint.

CelLab · Deliverable 2 · random forest fire with regrowth and lightning

Two runs with seed 42 print identical fingerprints at every step; seed 43 gives different ones. Nothing in the code uses any other source of randomness, which a test checks by scanning the source code. If an experiment gives no seed, one is chosen and written into the run folder, so even those runs can be repeated.
