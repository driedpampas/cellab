How count(), sum() and mean() work

def _aggregate(name: str, arg: ast.expr, ctx: EvalContext):
    if name == "count" and isinstance(arg, ast.Name) and arg.id in ctx.state_values:
        target = ctx.state_values[arg.id]  # count(NAME) shorthand
        per_neighbour = [neighbour == target for neighbour in ctx.neighbours()]
    else:
        per_neighbour = [np.broadcast_to(_evaluate(arg, ctx, neighbour), ctx.shape)
                         for neighbour in ctx.neighbours()]
    stacked = np.stack(per_neighbour)  # shape: (number of neighbours, *grid shape)
    if name == "count":
        return np.count_nonzero(stacked, axis=0)
    if name == "sum":
        return stacked.sum(axis=0)
    if name == "mean":
        return stacked.mean(axis=0)
    if name == "min":
        return stacked.min(axis=0)
    return stacked.max(axis=0)

The argument is evaluated once per neighbour, with nb = that neighbour’s shifted grid.

The results are stacked, then reduced over the stack.

Sandpile: count(nb >= 4) = how many neighbours topple.

Example: count(nb >= 4) in the sandpile. With 4 neighbours, the argument nb >= 4 is evaluated 4 times (nb = north view, west view, east view, south view). Each gives a True/False grid. They are stacked into a 4 x rows x columns array, and count_nonzero over the first axis gives, for every cell, how many of its neighbours have 4 or more grains.
