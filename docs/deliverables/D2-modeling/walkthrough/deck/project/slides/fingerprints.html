A 16-byte fingerprint for every generation

def fingerprint(grid: np.ndarray) -> bytes:
    h = hashlib.blake2b(digest_size=FINGERPRINT_SIZE)
    h.update(f"{grid.shape}|{grid.dtype.str}|".encode())
    h.update(np.ascontiguousarray(grid).tobytes())
    return h.digest()

Same grid → same 16 bytes. Two different grids collide with probability about 1 in 2¹²⁸.

Comparing 16 bytes is much cheaper than comparing whole grids, and storing them is cheap: a million steps take 16 MB.

def record(self, fp: bytes) -> None:
    step = len(self.fingerprints)
    if fp in self.first_seen:
        if self.repeat is None:
            self.repeat = (self.first_seen[fp], step)
    else:
        self.first_seen[fp] = step
    if (self.standstill is None and self.fingerprints
            and fp == self.fingerprints[-1]):
        self.standstill = step
    self.fingerprints.append(fp)

first_seen: fingerprint → first step · repeat: first (earlier, later) pair · standstill: first step equal to the one before

History.record is called once per generation, step 0 included. Three small facts are all the five questions need: the first step each fingerprint appeared, the first time any fingerprint comes back (a repeat), and the first time a grid equals the grid just before it (a standstill). The if in record is wrapped over two lines here to fit the slide; in the file it is one line.
