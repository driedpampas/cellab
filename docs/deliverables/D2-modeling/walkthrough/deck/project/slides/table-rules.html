A pattern table becomes a lookup in an array

def evaluate(self, ctx: EvalContext) -> tuple[np.ndarray, np.ndarray]:
    # Each pattern becomes a number ("code"), like reading the cells as digits in base `base`.
    code = np.zeros(ctx.shape, dtype=np.int64)
    for offset in self.offsets:
        cell = ctx.grid if not any(offset) else ctx.views.at(offset)
        code = code * self.base + (cell.astype(np.int64) - self.lowest)
    return self.listed[code], self.results[code]

The table in rule30.json lists the 8 patterns of (left, self, right), just like the brief. When the file is loaded, build_table_rule turns it into two arrays: listed (is this pattern in the table?) and results (what it produces). At run time, every cell's pattern is turned into its code at once, and two array lookups give the answer. Patterns not listed fall through to the next rule.
