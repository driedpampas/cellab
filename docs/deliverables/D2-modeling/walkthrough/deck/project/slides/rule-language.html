def check(self, node: ast.AST, inside_aggregate: bool) -> None:
    if isinstance(node, ast.Call):
        self.check_call(node, inside_aggregate)
        return
    if not isinstance(node, _ALLOWED_NODES):
        self.fail(f"{type(node).__name__} is not allowed in rules")
    if isinstance(node, ast.Constant) and (isinstance(node.value, str) or not isinstance(node.value, (int, float))):
        self.fail("only numbers and True/False can be written literally (write state names without quotes)")
    if isinstance(node, ast.Name):
        self.check_name(node.id, inside_aggregate)
    for child in ast.iter_child_nodes(node):
        self.check(child, inside_aggregate)

Allowed: numbers, names, arithmetic, comparisons, and/or/not, if-else, and our 9 functions.

check is recursive: it checks a node, then all its children, so the whole tree is covered. check_call handles function calls separately: it only accepts our known functions, with the right number of arguments, and forbids an aggregate inside another aggregate. check_name rejects unknown names and suggests the closest known one, ignoring upper or lower case.
