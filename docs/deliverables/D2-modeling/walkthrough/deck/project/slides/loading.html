Three layers of checks before anything runs

1

Is it JSON?

read_json gives the line and column of a syntax error.

bad.json, line 3, column 19: invalid JSON (Expecting value)

2

Right structure?

A pydantic model checks required fields, types, and catches misspelled field names.

neighborhood: unknown field (check the spelling)

3

Does it make sense?

States, edges, parameters and grids are checked together. Every rule is compiled here.

rules[1].when: unknown name 'FIER' (did you mean 'FIRE'?)

The result is an Automaton object with no text left in it: states are numbers, the neighbourhood is a list of offsets, every rule is compiled.

This is constraint checking, the Lab 5 topic: a file is valid only if all its parts are consistent with each other. Layer 3 is in build_automaton (automaton.py) and load_experiment (experiment.py). Every message names the file and the field, which errors.py's InputFileError guarantees. tests/test_validation.py feeds over 50 broken files and checks each message.
