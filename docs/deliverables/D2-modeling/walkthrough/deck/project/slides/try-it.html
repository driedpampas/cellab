Try it yourself

.venv\Scripts\activate
cellab check automata/*.json experiments/*.json
cellab run experiments/forest_fire_brief.json --show
cellab run experiments/rule30_ring16.json --stop-at 2000
cellab resume runs/<experiment>/<date_time>
cellab run experiments/forest_fire_regrowth.json --seed 42 --trace
cellab render runs/<...>
python -m pytest

Then read docs/GUIDE.md (the code) and docs/FILE_FORMATS.md (writing your own automaton).
