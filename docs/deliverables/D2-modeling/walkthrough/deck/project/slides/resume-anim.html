Animated · the crash test from test_reproducibility.py

Checkpoints, a crash, and an exact resume

Checkpoint every 10 steps.

Crash at 25: files hold 0–24, the checkpoint says 20.

Resume cuts back to 20 and goes on.

The result equals a run that never crashed.

The test replaces the engine's step function with one that raises an error at its 25th call, simulating a power cut. Then it reopens the folder, checks it restarted at step 20, finishes the run, and compares fingerprints.bin, generations.bin and answers.json with an uninterrupted run of the same experiment and seed. They are identical.
