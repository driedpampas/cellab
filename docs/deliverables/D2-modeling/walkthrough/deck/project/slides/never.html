A certain “never”, and no false promises with random rules

def answer(self, ctx):  # the Occurs question
    history = ctx.history
    if self.fingerprint in history.first_seen:
        step = history.first_seen[self.fingerprint]
        return Answer(self.to_dict(), True, f"Yes, first at step {step}.", {"occurs": True, "first_step": step})
    if ctx.deterministic and history.cycle is not None:
        _, later = history.repeat
        text = (f"No, never: by step {later} the run had entered a cycle, so every grid it will "
                "ever show had already appeared, and this configuration was not one of them.")
        return Answer(self.to_dict(), True, text, {"occurs": False, "certain": True})
    text = ctx.undecided("the configuration did not appear")
    if not ctx.deterministic:
        text += f" Note: {RANDOM_NOTE}."
    return Answer(self.to_dict(), False, text, {"occurs": None})

Deterministic rules

After a repeat, every future grid has been seen. Not among them means never, with certainty.

Random rules

A repeated grid is not a cycle: the random numbers go on. The answer says so.

Out of budget

“Not decided within N steps (max_steps)”: never a guess.

The Occurs question shows all three kinds of answer in one function. An automaton "uses random numbers" if any of its rules calls random(); the Automaton object knows this (automaton.deterministic), and the questions use it to decide whether a repeat proves a cycle. The random case is tested in tests/test_questions.py with a coin-flip automaton.
