Where each future change goes, and what stays untouched

Future needWhere it goesUnchanged
A new automatona new JSON fileall code
A new rule functionexpressions.py (checker + _call)everything else
Movement / agentsa new update mode in engine.step (“update” field is reserved)runner, fingerprints, questions, storage, CLI
D3 datasetloop over experiments with seeds and parametersthe engine
D4 parserwrite an automaton JSON; load_automaton checks iteverything else
Graphical interfacecalls load_experiment, Run, render_runthe library
The design separates what changes often (automata, interfaces) from what should not (the engine and the run machinery). The checker in automaton.py already recognises the planned update modes "movement" and "agents" and says they are not available yet.
