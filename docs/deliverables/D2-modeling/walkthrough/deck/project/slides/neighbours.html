Every neighbour is the grid shifted: no loops over cells

class GridViews:
    def __init__(self, grid: np.ndarray, radius: int, edge_mode: str, edge_value):
        self.shape = grid.shape
        self.radius = radius
        if edge_mode == "wrap":
            self.padded = np.pad(grid, radius, mode="wrap")
        else:
            self.padded = np.pad(grid, radius, mode="constant", constant_values=edge_value)
    def at(self, offset: tuple[int, ...]) -> np.ndarray:
        """The value of the neighbour at `offset`, for every cell at once."""
        slices = tuple(slice(self.radius + d, self.radius + d + n) for d, n in zip(offset, self.shape))
        return self.padded[slices]

row:            a b c d e
padded (wrap):  e a b c d e a
view "left":    e a b c d  each cell sees its left
view "right":   b c d e a  each cell sees its right

Pad once, then each neighbour is a slice: NumPy hands back a view of the same memory, with no copying.

The grid is padded by "radius" cells: copied from the other side for wrap-around edges, or filled with the fixed edge value. Then at(offset) cuts the padded grid at a shifted position, and at every position that slice holds the neighbour at that offset. The same code works for 1D and 2D, and for any list of offsets. The rule language uses it for names like north and left, and for count/sum/mean over the neighbourhood.
