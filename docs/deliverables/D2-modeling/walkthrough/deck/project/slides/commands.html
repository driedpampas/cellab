The command line · cli.py

Six commands, no logic of their own

CommandWhat it does
cellab check FILE...validate automaton and experiment files
cellab run EXPERIMENTstart a run, answer the questions, save the folder
cellab resume FOLDERcontinue from the last checkpoint (--steps N: go further)
cellab answers FOLDERprint a finished run’s answers again
cellab show FOLDERprint one stored generation (--step K)
cellab render FOLDERpictures: first.png, last.png, run.gif or spacetime.png

Options for run and resume: --seed, --steps, --stop-at (stop cleanly at a step), --trace (print fingerprints), --show (print every grid).

Each command parses its arguments and calls the library. Library errors are printed as one line starting with "error:", never as a Python traceback, and the exit code is 1. This separation means a graphical interface later can call exactly the same functions: load_experiment, Run.start, run.advance and render_run.
