How a rule is evaluated for every cell at once

Each node of the tree is evaluated from the bottom up.

A node’s value is a whole grid: “self == TREE” is True or False for all 20 cells at once.

The top grid says where the rule applies: the 3 trees touching the fire.

This is the core trick that keeps the engine simple and fast: the evaluator never loops over cells. Names stand for whole grids (self is the grid, north is the grid shifted by one row, FIRE is the number 2), and NumPy applies every operator to all cells together. "and" combines two True/False grids cell by cell.
