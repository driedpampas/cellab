The big picture

What happens when you run an experiment

Two text files go in. Answers, pictures and a saved run come out.

The orange part is the loop that repeats every step: compute, fingerprint, save, check the questions.

Blue names are the files holding that stage’s code.

The animation walks through the stages in order. Everything before engine.step happens once. The four highlighted stages at the end form the loop that runs once per generation. The run stops when the experiment's steps are done and every question has an answer, or when max_steps is reached.
