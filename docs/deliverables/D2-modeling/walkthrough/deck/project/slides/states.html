def finish_step(self, work: np.ndarray) -> np.ndarray:
    if self.kind == "real" and self.decimals is not None:
        work = np.round(work, self.decimals)
    low, high = self.lowest, self.highest
    if low is not None and (work < low).any():
        raise RuleError(...)  # "... below the lowest allowed value ..."
    if high is not None and (work > high).any():
        raise RuleError(...)  # "... above the highest allowed value ..."
    return work.astype(self.dtype)

A step is computed in a wide number type (int64 or float64), so a rule like self - 1 on a cell holding 0 gives -1 instead of silently wrapping to 255 in a small uint8. finish_step then rounds real values if asked, checks the limits, and stores the grid in its normal type. The two messages at the bottom are real outputs from the tests in tests/test_rule_language.py.
