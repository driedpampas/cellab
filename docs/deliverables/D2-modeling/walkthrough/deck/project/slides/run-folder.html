Append-only records

Generation k starts at byte k × (grid size): any step can be read directly, and resuming just cuts the file back.

Atomic checkpoints

Written to checkpoint.tmp, then renamed. A crash leaves the old one or the new one, never half of one.

The folder is self-contained: it holds its own copies of the input files, so it can be resumed or drawn even if the originals change. The checkpoint stores the SHA-256 of automaton.json, and resume refuses to continue if that copy was edited, because continuing would mix two different automata. Checkpoints are forced to disk with fsync, which is slow on Windows, so the default is one checkpoint per 100 steps.
