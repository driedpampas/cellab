def grid_after(self, n: int) -> tuple[np.ndarray, int] | None:
    if n <= self.history.last_step:
        grid = self.captured[n] if n in self.captured else self.grid_at(n)
        return grid, n
    if self.deterministic and self.history.cycle is not None:
        start, length = self.history.cycle
        same = start + (n - start) % length
        return self.grid_at(same), same
    return None

The run continues while a question is unresolved, up to max_steps. Anything still open is answered “Not decided”, never guessed.

Each question is a small class with three jobs: capture_steps (which grids to keep), resolved (does the run know enough yet?), and answer. The runner's loop stops only when the experiment's steps are done and every question is resolved, or at max_steps. grid_after is the jump-ahead: this is how "state after 1,000,000 steps" of Rule 30 on 16 cells was answered after simulating only 6,074 steps.
