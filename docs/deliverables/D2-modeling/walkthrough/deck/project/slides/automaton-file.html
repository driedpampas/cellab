An automaton file says what the automaton is

{
  "name": "Forest fire",
  "dimensions": 2,
  "states": ["EMPTY", "TREE", "FIRE"],
  "neighbourhood": "von_neumann",
  "edges": {"type": "fixed", "value": "EMPTY"},
  "rules": [
    {"when": "self == FIRE", "then": "EMPTY"},
    {"when": "self == TREE and count(FIRE) >= 1",
     "then": "FIRE"}
  ],
  "otherwise": "self",
  "colors": {"EMPTY": "#e3dfd4", ...}
}

states: names become numbers inside the engine: EMPTY = 0, TREE = 1, FIRE = 2.

neighbourhood: “von_neumann” = the 4 cells above, left, right, below.

edges: beyond the grid there is EMPTY (or “wrap”: opposite sides touch).

rules: small expressions. For each cell, the first rule that applies decides.

otherwise: cells no rule touches stay as they are.

colors: only for pictures.

Nothing here is Python code: it is data. The two orange strings are the only "program" in the file, and they are not run as Python: our own evaluator reads them (see the rule language slides). The full field reference is in docs/FILE_FORMATS.md.
