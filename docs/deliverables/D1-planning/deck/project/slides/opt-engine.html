Technical options · simulation

Options for the simulation engine

OptionAdvantagesDisadvantages
Plain Python loopsSimple to writeSlow on large grids
NumPy, neighbours counted by convolution (our choice)Fast, short codeAwkward for movement and agents
Numba-compiled loops (for agents)Fast even with loopsExtra dependency
An agent framework such as MesaAgents and scheduling built inToo heavy for plain automata

Reason for our choice: NumPy covers the synchronous mode, which most examples use; Numba covers movement and agents, where cells must be processed in order.

CelLab · Deliverable 1 · highlighted rows = our choice

Counting neighbours as a convolution means one array operation per step instead of a loop over every cell, which is the standard fast way to simulate cellular automata in Python. Agents and movement need cells to be processed one at a time in a fixed order, so for those we compile loops with Numba.
