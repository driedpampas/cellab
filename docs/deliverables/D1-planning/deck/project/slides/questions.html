The five questions

The five questions the system must answer

1

What is the state after N iterations?

2

When does it reach a stable state?

3

Does a particular configuration ever occur?

4

How many cells of type X exist after N iterations?

5

Does it enter a cycle?

Our goal: all five, for every supported automaton.

Key fact

A finite grid with fixed rules has finitely many possible states.

So every run must eventually repeat a state, and then loop forever. That makes questions 2, 3 and 5 exactly answerable.

CelLab · Deliverable 1

The brief requires at least 3 of the 5; we aim for all 5. The key fact is the pigeonhole principle: with finitely many states and a deterministic rule, a repeat is guaranteed, and once a state repeats the future repeats too. Questions 1 and 4 are just running N steps.
