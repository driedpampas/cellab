The project

What the system should do

1

Describe

The user writes the automaton in plain English. The system checks it and asks about anything missing.

2

Simulate

Run N generations from a given or generated start. Show them, and store them if asked.

3

Answer

Five questions about how the world evolves, answered exactly from the simulation.

4

Predict

A trained model answers the same questions without simulating, and we measure how well.

All through one graphical interface: description, parameters, generations, answers.

CelLab · Deliverable 1

Steps 1 to 3 are the core requirements. Step 4 is our main bonus: building a dataset and validating it with a neural network. The interface requirements from the brief: enter a text description, set the number of generations, the initial state and whether to store intermediate generations, and view the states.
