Setting up the initial world

The brief says the starting grid can be set by the user or generated by rules. We plan to support four ways:

Drawn by hand

Click cells in the interface, or paste a grid as text

Random

A chosen share of each cell type, e.g. 70% trees

Patterns

A single cell in the centre, a stripe, a known shape

From the description

"Trees everywhere, one fire in the middle"

The random seed is saved with the experiment, so a random start can always be recreated.

CelLab · Deliverable 1

The initial world is part of the spec as its own section. The fourth option uses the same parser as the rules. Random starts are also what the dataset generator uses, which is why saving the seed matters.
