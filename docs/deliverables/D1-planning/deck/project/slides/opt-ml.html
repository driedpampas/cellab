CelLab · Deliverable 1 · highlighted rows = our choice and baseline

The brief allows a neural network or a reinforcement learning experiment. We choose a convolutional network because cellular automaton rules are local, which is exactly what convolutions model. Gradient boosting on simple features gives a strong baseline for the yes/no and count questions. Reinforcement learning stays as a stretch goal: an agent that changes a few cells of the start grid so that a target configuration appears.
