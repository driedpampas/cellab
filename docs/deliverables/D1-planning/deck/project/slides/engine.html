System design

Update modes in the simulation engine

Synchronous

Every cell computes its next state from the old grid, all at once.

Rule 30, Brian's Brain, cyclic, fire, epidemic, voter, crystal, sandpile, diffusion

Ordered movement

Contents move to other cells in a fixed order, with a rule for collisions.

Traffic, falling sand

Agents

The grid is the world. Agents with a position, direction or energy act in turn.

Langton's ant, predator–prey, Schelling, ecosystem

Shared by all three: grid storage, neighbourhoods, edges, seeds, cycle detection, saving.

CelLab · Deliverable 1

The four families from earlier map to three update modes; neighbour rules and numeric cells both use the synchronous mode. The hard design questions are in modes two and three: who moves first, and what happens when two things want the same cell. The brief leaves these open, so we will define and document them.
