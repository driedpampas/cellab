Scope

What the system will support

Supported

  • 1D or 2D grids of any size
  • Any finite set of cell types, or numeric values
  • 4 or 8 neighbours; fixed or wrapping edges
  • Rules based on a cell's type and its neighbour counts
  • Movement with a collision rule; simple agents
  • Randomness with a seed

Caught by the validator

  • A rule uses a cell type that was never declared
  • Two rules contradict each other
  • Something is missing, e.g. which neighbours count
  • Behaviour the format cannot express: refused with a reason, never guessed

The 15 examples will be included in the interface as ready-made spec files that the general engine runs.

CelLab · Deliverable 1

The brief asks for a system where a user describes an automaton, not a menu of 15. We read the 15 as the test set: we expect to be asked to run them, variants of them, or new ones like Game of Life. Since no system can accept any English description, we define clearly what we support, and the validator rejects anything else with an explanation.
