Our laptops

No NVIDIA GPU, 8 GB and 20 GB of RAM. Simulation, interface, tests, running the trained model, local language models up to 3B / 7B parameters.

Google Colab GPU

Dataset generation, training, fine-tuning. Checkpoints saved to Google Drive after every epoch.

Also considered: JavaScript (weak for ML), Java or C# (few ML libraries), C++ (slow to develop). Python has the libraries and runs on Colab.

CelLab · Deliverable 1

Both laptops have an Intel i7-1165G7 with integrated graphics, so anything that needs a GPU goes to Colab. Small language models run on a processor, slowly but well enough for short descriptions: about 1.5–3B parameters on the 8 GB laptop and up to 7B on the 20 GB one.
