Q3 · Does C ever occur?

If C has not appeared once the loop closes, it never will.

Implementation: a table from state hash to step number. One hash per step, not one grid.

CelLab · Deliverable 1

Run the automaton, and after each step store a fingerprint of the state with its step number. The moment a fingerprint is already in the table, we know everything: when the loop starts, how long it is, and that the future is just that loop forever. If the loop is longer than our step budget, we answer "not decided within N steps" rather than guess.
