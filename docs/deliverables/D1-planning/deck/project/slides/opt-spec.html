Technical options · representation

Options for representing an automaton

OptionAdvantagesDisadvantages
A Python class per automatonFastest to writeNot general; no text input possible
JSON spec with fixed rule types (our choice)General and easy to validateNeeds careful design for agents
A small custom rule languageVery expressiveNeeds its own grammar and interpreter
Code written by a language modelCan express anythingUnsafe and cannot be validated

Reason for our choice: the parser needs a clear target it can be checked against, and the engine must run new automata without new code.
