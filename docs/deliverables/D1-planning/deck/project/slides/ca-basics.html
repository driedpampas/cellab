Cellular automata in one slide

What a cellular automaton is

1

Grid

A row or a matrix of cells

2

Cell types

EMPTY, TREE, FIRE… or a number

3

Neighbourhood

Which cells a cell can see: left and right, the 4 sides, or all 8 around it

4

Rule

Every cell applies it at the same time, reading the old grid

Every one of the 15 examples is built from these four ingredients. The example is the forest fire grid from the project brief. Key detail: every cell decides using the old grid, otherwise fire would race across the whole forest in a single step. In code this means building a new grid from the old one each step.
