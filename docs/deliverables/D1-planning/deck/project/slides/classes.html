Wolfram sorted elementary automata into four classes by behaviour. Our main experiment tests whether prediction accuracy follows that order. A clear "it works here, it fails there, and here is why" is a stronger result than a model that only looks good. Rule 110 is famous for being able to perform any computation, which is another reason to expect it to resist shortcuts.
