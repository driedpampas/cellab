The simplest family

Elementary cellular automata

One row of 0/1 cells. Each cell looks at left, itself and right: 8 patterns, each mapped to 0 or 1.

Pattern111110101100011010001000Read as binary
Rule 300001111000011110 = 30
Rule 58 (lab)0011101000111010 = 58

Lab example, Rule 58 with fixed 0 edges: 0 [0001100] 0 → 0011010

Why 256

8 patterns, 2 choices each: 2⁸ = 256 rules. The 8 outputs, read as a binary number, are the rule's name.

Why it matters to us

A complete, small family. The 8 bits are a ready-made way to feed a rule into a neural network.
