CelLab · Deliverable 1 · highlighted rows = the options we compare

All options share the same validator. "Correct behaviour" means our parsed spec and a hand-written reference spec produce identical runs on 100 random grids; this catches specs that are valid but wrong, such as "at least two" read as "exactly two". The API model is the quality baseline; the local model is the bonus the brief recommends. The local model can be fine-tuned on Colab using description → spec pairs.
