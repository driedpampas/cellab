F1 is reported next to accuracy because the yes/no answers can be unbalanced: if most runs stabilise, accuracy alone rewards always saying yes. Reporting per rule class is what lets us test the hypothesis on the next slide. The parser has its own metrics, shown on the parsing options slide.
