Beyond 1D: after the elementary rules, we repeat the experiment on 2D automata such as forest fire and Brian's Brain.

CelLab · Deliverable 1

Encoding each cell type as its own layer of zeros and ones is the standard way to feed categories into a convolutional network, the same way an image has red, green and blue layers. Matching the padding to the automaton's edge rule means the network sees the same neighbourhoods the simulation does.
